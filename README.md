# 🐍 CodeTrace — Python Error Detective

CodeTrace is a beginner-friendly Python error analysis tool built with Python and Streamlit. It helps users identify common Python errors and understand them through simple explanations.

## ✨ Features

- **Syntax Error Detection:** Identifies common Python syntax mistakes.
- **Runtime Error Detection:** Displays common errors that occur during execution.
- **Simple Explanations:** Explains errors in beginner-friendly language.
- **Program Output:** Displays output from successfully executed code.
- **Interactive Interface:** Provides a simple web interface using Streamlit.

## 🛠️ Technologies Used

- Python
- Streamlit

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   streamlit run app.py
   ```

5. Open the local URL displayed in your terminal.

## 🎯 Project Goal

The goal of CodeTrace is to make Python errors easier to understand, especially for beginners who are learning programming.
